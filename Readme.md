# COZY CUP CAFE

## Project Description
Cozy Cup Cafe is a simple website project that presents a café’s atmosphere, menu, and services with a warm and cozy design.

## Features
- Cozy café-themed user interface
- Menu display for drinks and food
- Responsive layout
- Easy navigation
- Clean and simple design
